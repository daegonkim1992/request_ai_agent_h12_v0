## 설계 완료 판정 보류 (2026-11-04)

업무정의서 11.1에 따라 다음 네 설계 영역은 전체 완료로 처리하지 않는다. 기능 구현은 확정된 범위에서 계속할 수 있으나, 아래 보류 항목을 추정으로 구현하거나 완료로 표시하지 않는다.

| 설계 영역 | 보류 이유 | 해제 조건 |
|---|---|---|
| 업무정의서 정제 | 측정 기준·PCB 온도·풍량 단위·설치 세부·CAD 전달과 조건 정책이 미결정 | 업무 담당자가 기준과 정책을 확정하고 정의서에 반영 |
| 프로세스와 상태 정의 | 사유 코드·판단 지점·알림 대상·의뢰번호·희망 완료일·표준값 변경 기록이 검토 중 | 업무 담당자가 초안 규칙을 승인하고 정의서 및 규칙 데이터에 반영 |
| 사용자·권한 설계 | 개발용 HMAC 인증만 있으며 실제 사용자 운영 계약이 없음 | IdP/관리자 원천과 세션·동기화·권한 변경·감사 계약 확정 |
| 데이터와 첨부파일 설계 | PCB 이미지 외 일반 첨부파일의 운영·보안 정책이 없음 | CAD 등 파일 전달 방식과 형식·크기·검사·보존·접근·감사 정책 확정 |

## UX 착수 보류 항목 구분 (0.2, 2026-11-05)

이 구분은 UX 착수 순서를 위한 처리 원칙이며 업무 규칙을 확정하지 않는다. `확정 필요`는 입력 구조나 업무 흐름의 선택지가 아직 없어 UX에서 임의로 정할 수 없는 항목이다. `표현만 필요`는 UX 구조를 시작할 수 있으나, 미정인 값·정책을 임시 값이나 규칙으로 가정하지 않고 보류 상태로 드러내야 하는 항목이다.

| UX-8 | 2장, G-29, 11.1·11.2 — 실제 로그인·사용자·권한 운영 | 표현만 필요 | 역할과 소속 부서가 세션에서 제공된다는 업무 전제 아래 역할별 여정을 작성한다. 로그인·로그아웃·계정 관리·세션 만료 화면은 사용자·권한 운영 계약이 확정될 때까지 업무 UX 범위에 포함하지 않는다. |
