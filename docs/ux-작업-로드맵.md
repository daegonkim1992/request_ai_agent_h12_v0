# 해석의뢰 앱 UX·UI·개발 작업 로드맵

- 기준일: 2026-11-05
- 현재 단계: **1. 역할별 사용자 여정 정의**
- 작업 원칙: 한 세션은 이 문서의 작업 단위 하나만 처리한다. 작업 단위 밖의 문제를 발견하면 수정하지 않고 `spec-gaps.md`에 기록하거나 다음 작업으로 등록한다.

## 1. 기준 문서와 우선순위

1. `해석의뢰_업무정의.md`: 업무 규칙의 유일한 정본이다.
2. `spec-gaps.md`: 정본에 아직 반영되지 않은 해석·보류·결정 이력이다. 업무 의미를 바꾸는 결정을 이 문서만으로 확정하지 않는다.
3. 이 문서: 작업 순서, 범위, 상태, 인수인계 기준을 관리한다.
4. 이후 만드는 UX·UI·기술 문서: 상위 두 업무 문서를 해석해 표현한다. 충돌하면 상위 문서를 따른다.

## 2. 상태 표기

| 상태 | 의미 |
|---|---|
| `대기` | 아직 시작하지 않았다. 선행 작업이 끝나야 한다. |
| `진행 중` | 현재 세션에서 처리 중이다. |
| `검토 대기` | 산출물은 준비됐고 업무 담당자 또는 사용성 검토가 필요하다. |
| `결정 필요` | 업무 의미가 갈리므로 임의로 정할 수 없다. |
| `완료` | 완료 조건과 검증 기록을 충족했다. |
| `보류` | 현재 단계에서는 결정하지 않는다. `spec-gaps.md`에 근거가 있어야 한다. |
